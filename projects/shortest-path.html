PROJECT

Shortest Path Analysis

Network-based shortest path analysis using transportation network data and the A* algorithm.

Overview

This project focuses on finding efficient routes between origin and destination points using a road network.

Tools Used

  • QGIS
  • Python
  • OpenStreetMap
  • A* algorithm

Methodology

  • Prepare the road network.
  • Identify network nodes and links.
  • Define origin and destination points.
  • Apply the A* shortest path algorithm.
  • Extract the resulting route through the transportation network.
