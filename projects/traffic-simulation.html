PROJECT

Traffic Simulation

Traffic network modelling and simulation using Aimsun and SUMO for analysing transportation networks and traffic operations.

Overview

This project focuses on developing and analysing transportation network models using microscopic traffic simulation tools.

Software Used

  • Aimsun
  • SUMO
  • QGIS

Workflow

  • Prepare the transportation network.
  • Define network links and intersections.
  • Configure traffic demand and vehicle movements.
  • Define traffic control and simulation parameters where required.
  • Run the traffic simulation.
  • Analyse traffic operation and network performance.
